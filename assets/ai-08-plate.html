applied research note ·ai-08 ·engineering memory ·where does the reasoning go when the meeting ends?

The meeting forgets. The pull request remembers.

ithe human loop
reputation arbitrates, memory decays.
  1. 01The meeting"Sam, go check ClickHouse vs Influx."
  2. 02Sam's week of explorationtrials, dead ends, corrected assumptions
  3. 03The meeting, againreputation decides; the team converges
  4. 04One final docwhat was decided. nothing else.
rejected options, corrected beliefs, side findings: all evaporate by next sprint.
iithe agent loop
every step leaves a queryable artifact.
  1. 01Pull requestthe work, as it happens
  2. 02Agent reviewchallenged by other agents, then merged
  3. 03ADRs · investigations · pitfallsdecisions, dead ends, mistakes: kept
  4. 04Vault, then memory graphlinked notes, then a queryable index
  5. 05The gateno code edit without querying memory first
the next decision starts from everything above, not from what anyone remembers.
